# System photos

Drop a product photo or spec sheet here to have it appear on the **recommended-system
page** of any report where that system is the recommendation. Easiest way: use the
**System photo** uploader in the website's settings panel.

Name each file with the system's key:

| File name | System |
|-----------|--------|
| `standard_mixed_bed.png` | Standard Softener + Carbon System |
| `dual_tank_city.png` | Dual-Tank City Water System |
| `dual_tank_well.png` | Dual-Tank Well System |
| `peroxide.png` | Complete Iron & Sulfur Removal (Peroxide) |
| `salt_free.png` | Salt-Free Conditioning + Carbon System |

`.png`, `.jpg`, and `.jpeg` are supported. A landscape image (roughly 4:3 or wider) looks
best — it's placed full content-width under the recommendation banner.

The system keys come from `config.json` → `systems`.
