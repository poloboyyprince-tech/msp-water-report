# MSP Pure Water — website v2 (premium redesign, GoHighLevel-native)

Static, dependency-free site generated by `build.py` from JSON content and a
small component library. Output in `dist/` (clean URLs) deploys to any static
host (Netlify, Cloudflare Pages, GitHub Pages, S3). `_redirects` and `_headers`
are Netlify/Cloudflare syntax; mirror them in the host config if different.

    python3 build.py                 # rebuild dist/
    python3 -m http.server 8942 --directory dist   # local preview

- Content: `src/data/*.json` (systems, problems, FAQ, cities, reviews)
- Business facts: `src/config/site.json`
- GoHighLevel: `src/config/ghl.config.js` — see INTEGRATION.md
- Styles: `src/css/site.css` · Scripts: `src/js/*.js` · Images: `src/img/`
- Hero film: `src/video/hero.mp4` (+ `hero-mobile.mp4`, `hero.webm`) and
  `src/img/hero-poster.jpg`. If the video is absent the hero falls back to the
  poster image automatically.
